# My Portfolio Website

Portfolio website project for Full Stack Web Development Bootcamp assignment.

## Description

This project is a personal portfolio website built using HTML, CSS, and JavaScript.  
The purpose of this assignment is to practice Git and GitHub version control workflows such as commit, push, pull, branching, merging, tags, and repository management.

- Responsive portfolio website
- Professional bio section
- Project showcase section
- Simple and clean UI
